🚀 Facebook Account Creator

Auto-create accounts with @yopmail.com and extract confirmation codes automatically

📧 @yopmail.com | 🔑 Auto Confirmation Code | ⚡ 2 accounts/2min

📝 Create Account (GET Method)

GET http://localhost:5000/create

Click the button below to create a Facebook account automatically

⚙️ Optional Parameters
firstName
?firstName=John
lastName
?lastName=DelaCruz
gender
?gender=M (or F)
birthday
?birthday=1990-05-15
Example with parameters:
http://localhost:5000/create?firstName=John&lastName=DelaCruz&gender=M

📋 Response

💡 Click the button above to create an account

⚙️ How It Works

1️⃣ Create Account
Facebook account created with random Filipino profile
2️⃣ Send Email
Facebook sends confirmation email to @yopmail.com
3️⃣ Extract Code
API automatically fetches confirmation code from Yopmail
4️⃣ Return Result
Complete account details + confirmation code
